`GET /consumer/v1/me/addresses/{addressId}/prices`

Set the key and address ID as described in [Quick start](/consumer-api/quickstart). The curl sample uses environment variables; no interactive requests are sent from these docs. Choose dates available for your address.

See [Time and ranges](/consumer-api/time-and-ranges) and [Data interpretation](/consumer-api/data-interpretation) before combining results.
