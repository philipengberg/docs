The Enterprise API is intended for business-to-business integrations. Access is arranged directly with Min Strøm, with a separate API key and secret.

Existing third-party integrations continue using the same `/thirdParty` endpoints and authentication. The Enterprise name identifies the intended audience; it does not deprecate or change the API.
